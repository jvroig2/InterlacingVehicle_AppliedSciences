# Interlaced Implementation of Robust Controllers for Autonomous Vehicle Lateral Guidance: A Study of Dynamic Partitioning Criteria

Authors: José Vicente Roig Roig; Julián Mauricio Salt Ducaju; Julián Salt Llobregat.
Submitted to: Applied Sciences (MDPI).
Submission date: To be confirmed.
Last updated: 28 October 2026.

This repository contains the supplementary material for the study of the influence of modal block ranking criteria on the interlaced implementation of a robust controller for autonomous vehicle lateral guidance. Criteria based on modal speed, static gain, input–output coupling, and Hankel singular values are compared for interlacing factors N = 4 to N = 8.

### `.m` files (MATLAB code and functions)

- AnalisisReg.m: Code for analyzing the reference controller and its modal properties using each ranking criterion.
- regdiagsep.m: Function that partitions a discrete-time system into subspaces after transforming it into a modal block-diagonal form and ordering its poles from fastest to slowest. Generates state-space subsystems that can be used to construct controller partitions.
